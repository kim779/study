# 잔고 매입금액/평가금액/수익률 계산 공식 정리 (2026-07-08)

## 모듈 개요

`Remain.cpp` / `Remain.h` — `CRemain` 클래스, 실시간 잔고 계산 모듈.
지난번(2026-06-11) 작업은 NXT 종목코드(`N.`/`M.`) 파싱 이슈였고, 이번은 별개로
"매입금액/평가금액/수익률을 어떤 공식으로 구하는지"를 소스 기준으로 정리하는 작업.

---

## 1. 데이터 필드 매핑 (DefineAll.h `struct s_rec` ↔ CRemain 멤버)

서버 응답(`s_rec`)과 `CRemain` 멤버 변수 대응 관계. **`m_rprice`라는 이름과 달리
실제로는 "가격(단가)"이 아니라 "평가금액"(수량×단가)을 담는 변수이므로 혼동 주의.**

| s_rec 필드 | 의미 | CRemain 멤버 | 비고 |
|---|---|---|---|
| `pamt` | 매입평균가 | `m_pmaip` | 평균단가 |
| `mamt` | 매입금액 | `m_maip` | |
| `curr` | 현재가 | `m_curr` | |
| `camt` | 평가금액 | `m_rprice` | 이름은 "price"지만 값은 금액(수량×단가) |
| `tamt` | 평가손익 | `m_pgsonik` | |
| `srat` | 평가수익률 | `m_psuik` | |
| `samt` | 신용금액(대출금) | `m_symt` | |
| `jqty` | 잔고수량 | `m_remain`, `m_amt` | |
| `xqty` | 매도가능수량 | `m_possible` | |

실시간 체결 이벤트(`symbolMap`, MapWnd.cpp)의 관련 키:

| RT 코드 | 의미 |
|---|---|
| `RT_CPRICE`("916") | 체결가 |
| `RT_CAMT`("931") | 체결량 |
| `RT_MOD`("999") | Mod Value(가격 배수, 0이면 1로 보정) |
| `RT_CTSYMT`("933") | 신용금/대출상환금 |
| `RT_GUBN`("912") | 매수/매도 구분 |
| `RT_STATE`("988") | 주문상태(체결/미체결/취소확인 등) |
| `RT_CREDIT`("911") | 신용구분(05=유통대주) |

## 2. 계산이 일어나는 3개 진입점

1. **`ParsingRemainData()`** — 서버 잔고조회(배치) 응답 수신 시, 서버가 내려준 값을
   로컬 수수료/세금 정책으로 다시 계산.
2. **`CalRemainData()`** — 실시간 체결 발생 시, 매입금액/평균단가를 체결 내역 기준으로 재계산.
3. **`CalPgsonik()`** — 실시간 시세(현재가) 변동 시, 평가금액/평가손익/수익률을 재계산.

## 3. 체결 반영 시 매입금액/평균단가 공식 (`CalRemainData`, Remain.cpp:612-762)

### 3-1. 신규 잔고 최초 체결 (`bNewCode == true`, L612-651)

```
평균단가(m_pmaip) = 체결가(RT_CPRICE) / Mod값(RT_MOD, 0이면 1)
매입금액(m_maip)  = 평균단가 × 체결수량(RT_CAMT)
                    신용대출 계좌면: 매입금액 -= 신용대출금액(m_symt)
가능수량(m_possible) = 체결수량
```

### 3-2. 기존 잔고 + 매수 체결, 일반(비유통대주) (L668-683)

가중평균 방식:

```
신매입금액(maipS) = 기존잔고(m_remain) × 기존평균단가(m_pmaip)
                    + 체결단가(cpriceS) × 체결수량(nContAmt)
신잔고(m_remain)  = 기존잔고 + 체결수량
평균단가(m_pmaip) = maipS / 신잔고
매입금액(m_maip)  = maipS
가능수량(m_possible) += 체결수량
```

### 3-3. 유통대주(credit==5) 매도 체결 = 공매도 잔고 증가 (L705-717)

방향만 반대일 뿐 3-2와 동일한 가중평균 공식.

### 3-4. 기존 잔고 + 매도 체결, 일반 (L719-732)

```
잔고(m_remain) -= 체결수량
매입금액(m_maip) = 평균단가(m_pmaip, 불변) × 남은잔고(m_remain)
```
→ 평균단가는 그대로 두고, 매입금액만 잔고 비례로 축소. 잔고가 0이 되면
해당 종목 잔고 삭제(`CHEG_DELETE`).

### 3-5. 유통대주 상환 체결 (credit==5, L671-675, L685-701)

```
잔고(m_remain) -= 체결수량
매입금액(m_maip) = 평균단가(m_pmaip) × 남은잔고(m_remain)
```

## 4. 시세 변동 시 평가금액/평가손익/수익률 공식 (`CalPgsonik`, Remain.cpp:793-1113)

공통 원칙(주석에 명시, L795-799 / L1015-1018):
```
평가금액 = 현재가 × 잔고, 신용대주는 부호 반대
평가손익 = 평가금액 - 매입금액
수익률   = 평가손익 × 100 / 매입금액
```

### 4-1. 수수료 적용(`m_dFee > 0`, L793-1012)

```
평가금액(rprice) = 현재가(m_curr) × 잔고(m_remain)
수수료(dmass) = RoundDown(평가금액 × 수수료율 m_dMass)
세금(dtax)   = Round(평가금액 × 세율 m_dTax)

세금 면제 종목(ETF/ETN/우선주Q코드/BDC상품, L838):
    평가금액 = 평가금액 ∓ (수수료 + 저축료 m_dSave)   (매수 '-', 대주매도 '+')
그 외 종목:
    평가금액 = 평가금액 ∓ (수수료 + 세금 + 저축료)

매입금액(dmaip):
    직전에 체결이 있었으면(m_bchg=true):
        dmaip = 평균단가(m_pmaip) × 잔고(m_remain)
                신용대주 아니면 신용대출금액(m_symt) 차감
    체결이 없었으면: 기존 원매입금액(m_omaip) 유지
    m_dFee==1이면 매입금액에도 수수료 반영 (대주는 차감, 그 외는 가산)

평가손익(dSonik) = 평가금액 - 매입금액   (대주는 ×(-1))
수익률           = 평가손익 × 100 / 매입금액
```

### 4-2. 수수료 미적용(`m_dFee == 0`, L1013-1113)

```
평가금액 = 현재가 × 잔고        (수수료/세금 미반영)
매입금액 = 4-1과 동일한 m_bchg 분기 로직, 단 수수료 가산 없음
평가손익 = 평가금액 - 매입금액  (대주는 ×(-1))
수익률   = 평가손익 × 100 / 매입금액
```

### 4-3. BEP(손익분기 단가, `m_pbep`) 공식 (L890-939)

```
세금 면제 종목(ETF/ETN/Q/BDC):
    매수: BEP = (평균단가×잔고 + RoundDown(평균단가×잔고×수수료율)) / (잔고×(1-수수료율))
    대주: BEP = (평균단가×잔고 - RoundDown(평균단가×잔고×수수료율)) / (잔고×(1+수수료율))

일반 종목(세금 포함):
    매수: BEP = (평균단가×잔고 + RoundDown(평균단가×잔고×수수료율))
                / (잔고×(1-수수료율-세율))
    대주: BEP = (평균단가×잔고 - RoundDown(평균단가×잔고×수수료율)
                 - Round(현재가×잔고×세율)) / (잔고×(1+수수료율))
```

## 5. 종목유형별 세율/수수료율 분기 (`CalPgsonik`, `ParsingRemainData` 공통)

| 조건 플래그 | 세율(m_dTax) | 비고 |
|---|---|---|
| `m_b3RDCode` (K-OTC) | `TAX_RATE_K_OTC` = 0.002 | 창구주문(`m_iMcgb==0`)이면 수수료율 0.0015 고정 |
| `m_bKONEXCode` | `TAX_RATE_KONEX` = 0.001 | |
| `m_bSJSuikCode` | `TAX_RATE_SJSUIK` = 0.0 | |
| `m_iCodetype == BDCpstType / BDCicyType` | 0 | BDC 상품 |
| 그 외 | `TAX_RATE` = 0.002 | 일반 |

세금(m_dTax) 완전 면제 대상(수수료+저축료만 적용, L838/L924/L315/L415):
`J코드(7자리, 일반 상장주식 아닌 특수) || ETF/ETN(m_betf) || Q코드 || BDC상품(BDCpstType/BDCicyType)`

신용대주(`m_creditS == "05"`)는 모든 손익/평가금액 계산에서 부호가 반전됨
(공매도 포지션이므로 주가 상승 = 손실 구조).

------------------------------------------------------------------------------
 1. 목적
------------------------------------------------------------------------------
 송수신 전문 압축(LZW)과 파일 압축/해제를 axSock 등에서 공용으로 쓰도록 분리한 모듈.
 기존 소스에 흩어져 있던 CCompress / CZip 을 핸들 기반 C API 로 감쌌다.

------------------------------------------------------------------------------
 2. 사용 방법
------------------------------------------------------------------------------
 (1) 메모리 압축 (전문)
     HLZW h = LZW_Open(13);
     int outLen = LZW_Compress(h, in, inLen, out);       // 반환 = 압축 결과 길이
     int rawLen = LZW_Decompress(h, in, inLen, out);     // 반환 = 해제 결과 길이
     LZW_Close(h);

 (2) 파일 압축/해제
     LZW_CompressFile  ("원본파일", "압축파일", keepOriginal);   // 반환 1 성공 / 0 실패
     LZW_DecompressFile("원본파일", "압축파일", keepOriginal);

------------------------------------------------------------------------------
 3. 함수 설명
------------------------------------------------------------------------------
 HLZW LZW_Open(int bits)
   - 압축 객체(CCompress) 생성.
   - bits : 13 / 16 (사전 비트 수) - ※ 현재는 무시됨 (TODO: 코어 통합 단계에서 반영)

 int LZW_Compress(HLZW h, const unsigned char* in, int inLen, unsigned char* out)
   - 반환 : 압축된 길이, h 가 NULL 이면 -1
   - ※ out 버퍼 크기를 받지 않는다 → 호출측이 충분한 크기를 보장해야 함
     (LZW 는 압축 불가 데이터에서 입력보다 커질 수 있음)

 int LZW_Decompress(HLZW h, const unsigned char* in, int inLen, unsigned char* out)
   - 반환 : 해제된 길이, h 가 NULL 이면 -1
   - ※ out 버퍼 크기를 받지 않는다 → 원문 최대 길이 이상의 버퍼 필요

 void LZW_Close(HLZW h)
   - 압축 객체 해제 (NULL 허용)

 int LZW_CompressFile(const char* ofname, const char* cfname, bool keepOriginal)
 int LZW_DecompressFile(const char* ofname, const char* cfname, bool keepOriginal)
   - ofname : 원본 파일, cfname : 압축 파일
   - keepOriginal = true : 작업 전에 원본을 <이름>_YYMMDDHHMM.<확장자> 로 복사해 둠
     (CZip 내부에서 원본을 지우는 경우 대비)
   - 반환 : 1 성공 / 0 실패

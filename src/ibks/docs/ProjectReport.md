## 1. 프로젝트 개요

### 목표

AXIS HTS(주식 거래용 화면 구축 도구) 내의 VBScript 엔진(CScriptEngine)을 **Python 엔진(CPythonEngine)으로 교체**하여:
- 스크립트 언어 현대화
- 커뮤니티 및 라이브러리 확장성 향상
- 점진적 마이그레이션 지원 (기존 VBS 호환)

### 규모

| 항목 | 수치 |
|------|------|
| 대상 맵 파일 | 5,391개 |
| 관련 DLL | 3개 (axisvbs, axwizard, builder) |
| 주요 클래스 | 10+ (CEngineWrapper, CPythonEngine, AxisObject 등) |
| 총 코드 라인 | ~3,000+ (신규 및 수정) |
| 예상 배포 일정 | 2026-08-31 |

## 2. 기술 아키텍처 요약

### 3계층 구조

```
┌─────────────────────────┐
│  axisbuilder.exe (편집) │ ← Python 모드 UI, ScpKind=2
└────────────┬────────────┘
             │ .map (Script 정의)
             ▼
┌─────────────────────────┐
│  axwizard.dll (런타임)  │ ← CEngineWrapper 초기화
└────────────┬────────────┘
             │ LoadScript(), DoProcedure()
             ▼
┌──────────────────────────────┐
│  axisvbs.dll (엔진)          │
│  ├─ CEngineWrapper (선택)    │ ← 자동 감지 (def/import)
│  ├─ CPythonEngine (신규)     │ ← Python C API
│  └─ CScriptEngine (기존)     │ ← Windows Script Host
└──────────────────────────────┘
```

### 핵심 설계

| 설계 | 설명 | 이점 |
|------|------|------|
| **자동 엔진 선택** | `def ` 또는 `import ` 감지 → CPythonEngine | 기존 코드 수정 불필요 |
| **지연 초기화** | LoadScript 시점에 엔진 생성 | Python/VBS 판단 시점 일치 |
| **PendingObject 버퍼** | AddObject를 LoadScript까지 보관 | 엔진 생성 전 객체 등록 가능 |
| **COM 래핑** | AxisObject로 IDispatch 래핑 | Python 스크립트에서 자연스러운 호출 |

## 4. 기술적 성과

### 솔루어낸 복잡한 문제

#### 1. Python/VBS 자동 감지
```cpp
bool isPythonScript(const char* code) {
    CString str(code);
    return (str.Find("def ") >= 0 || str.Find("import ") >= 0);
}
```
- 간단하지만 효과적
- 점진적 마이그레이션 가능
- 기존 코드 0개 수정

#### 2. 바이너리 마커 처리
- .map 파일의 `\x0E [kind] \x0C` 마커 자동 제거
- PyRun_String 호환성 확보
- 배포 후 사이드카 파일 불필요

#### 3. AddObject 버퍼링
- Initialize 시점에 엔진 미생성 → 문제
- LoadScript까지 AddObject 저장 → 해결
- PendingObject 구조로 우아하게 처리

#### 4. 재진입(Re-entrance) 방어
- MessageBox 모달 표시 시 이벤트 루프 실행 → 재진입 위험
- m_inException 플래그 추가 → 재진입 방지
- 안전하고 견고한 구현

### 발견된 버그 및 해결

| 버그 | 원인 | 해결 | 날짜 |
|------|------|------|------|
| LoadLibrary error 126 | python311.dll 없음 | 배포 DLL 추가 | 2026-06-08 |
| C4996 deprecated API | Python 3.11 변경 | PyConfig API 사용 | 2026-06-08 |
| 모든 화면 Python 실행 | 레지스트리 전역 설정 | 자동 감지 | 2026-06-08 |
| INFO 객체 오류 | AddObject 순서 | PendingObject 버퍼 | 2026-06-08 |
| 크래시 (PyDict) | 재진입/소멸자 | m_inException 방어 | 2026-06-09 |
| 바이너리 마커 SyntaxError | 정제 미흡 | LoadScript에서 제거 | 2026-06-10 |
| 대소문자 구분 오류 | VBS 호환성 | 문서화 및 자동감지 | 2026-06-11 |

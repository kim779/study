# 차트 개발에서 자주 사용하는 좌표 변환 및 선형 매핑 공식

MFC / C++ 기반의 HTS 차트를 개발할 때 자주 사용하는 **데이터 ↔ 화면 좌표 변환 공식**을 정리한다.

---

## 1. 값 → Y 좌표 변환

차트의 가격이나 지표 값을 화면의 Y 좌표로 변환한다.

```cpp
y = top + height * (maxValue - value) / (maxValue - minValue);
```

### 의미

```text
maxValue → 화면 위쪽
minValue → 화면 아래쪽
```

Windows 화면 좌표계는 Y가 아래로 증가하기 때문에 `maxValue - value` 형태가 사용된다.

### 예

```cpp
maxValue = 100;
minValue = 0;
height = 500;
```

| value | Y 위치 |
|---:|---:|
| 100 | 0 |
| 75 | 125 |
| 50 | 250 |
| 25 | 375 |
| 0 | 500 |

### MFC 예제

```cpp
int GetYPos(
    double value,
    double maxValue,
    double minValue,
    const CRect& rect)
{
    const double range = maxValue - minValue;

    if (range <= 0.0)
        return rect.bottom;

    const double y =
        rect.top +
        rect.Height() * (maxValue - value) / range;

    return static_cast<int>(y);
}
```

# 2. Y 좌표 → 값 역변환

마우스의 Y 좌표를 실제 가격이나 지표 값으로 변환할 때 사용한다.

```cpp
value =
    maxValue -
    (y - top) *
    (maxValue - minValue) /
    height;
```

### 예

```cpp
maxValue = 100;
minValue = 0;
height = 500;
y = 250;
```

결과:

```cpp
value = 100 - 250 * 100 / 500;
//      = 50
```

즉,

```text
화면 Y = 250
      ↓
가격 = 50
```

차트의 **Crosshair / 마우스 가격 표시** 등에 사용한다.

---

# 3. 값 → 0~1 정규화

값을 0~1 범위로 변환한다.

```cpp
ratio = (value - minValue) /
        (maxValue - minValue);
```

결과:

```text
minValue → 0.0
중간값   → 0.5
maxValue → 1.0
```

### 예

```cpp
minValue = 100;
maxValue = 200;
value = 150;
```

```cpp
ratio = (150 - 100) / (200 - 100);
//      = 0.5
```

이것을 **Normalization(정규화)**이라고 한다.

---

# 4. 0~1 비율 → 실제 값

3번 공식의 역변환이다.

```cpp
value =
    minValue +
    ratio * (maxValue - minValue);
```

### 예

```cpp
minValue = 100;
maxValue = 200;
ratio = 0.25;
```

```cpp
value = 100 + 0.25 * (200 - 100);
//      = 125
```

---

# 5. 두 값 사이의 선형 보간

가장 중요한 공식 중 하나이다.

```cpp
result = a + (b - a) * t;
```

여기서 `t`는 0~1 사이의 비율이다.

```text
t = 0.0 → a
t = 0.5 → 중간값
t = 1.0 → b
```

### 예

```cpp
a = 100;
b = 200;
t = 0.25;
```

```cpp
result = 100 + (200 - 100) * 0.25;
//      = 125
```

이것을 **Linear Interpolation(LERP)**이라고 한다.

---

# 6. 한 범위의 값을 다른 범위로 변환

예를 들어

```text
입력 범위 : 0 ~ 100
출력 범위 : 300 ~ 600
```

으로 변환한다.

공식:

```cpp
result =
    outMin +
    (value - inMin) *
    (outMax - outMin) /
    (inMax - inMin);
```

### 예

```cpp
value = 50;

inMin = 0;
inMax = 100;

outMin = 300;
outMax = 600;
```

```cpp
result =
    300 +
    50 * (600 - 300) / (100 - 0);

// 450
```

따라서:

```text
0   → 300
25  → 375
50  → 450
75  → 525
100 → 600
```

UI Slider, Progress Bar, Gauge, 차트 등에 매우 자주 사용된다.

---

# 7. Index → X 좌표

차트의 봉 번호(Index)를 화면 X 좌표로 변환한다.

```cpp
x =
    left +
    index * width /
    (count - 1);
```

예:

```cpp
left = 50;
width = 1000;
count = 100;
```

이면:

```text
index 0  → X = 50
index 25 → X ≈ 300
index 50 → X ≈ 550
index 75 → X ≈ 800
index 99 → X = 1050
```

주식 차트의 **시간축 / 봉 위치 계산**에 사용한다.

---

# 8. X 좌표 → Index

마우스 X 좌표로 어떤 봉을 가리키는지 계산한다.

```cpp
index =
    (x - left) *
    (count - 1) /
    width;
```

예:

```cpp
left = 50;
width = 1000;
count = 100;
x = 550;
```

```cpp
index =
    (550 - 50) * 99 / 1000;

// ≈ 49
```

Crosshair에서 **현재 마우스가 어느 봉을 가리키는지** 계산할 때 사용한다.

---

# 9. 등락률 계산

주식 프로그램에서 매우 자주 사용하는 공식이다.

```cpp
changeRate =
    (currentPrice - basePrice) /
    basePrice * 100.0;
```

예:

```cpp
basePrice = 50000;
currentPrice = 52000;
```

```cpp
changeRate =
    (52000 - 50000) / 50000 * 100;

// 4%
```

# 10. 가격 변화량

등락률과 함께 자주 사용한다.

```cpp
change =
    currentPrice - basePrice;
```

예:

```cpp
basePrice = 50000;
currentPrice = 52000;
```

```cpp
change = 2000;
```

즉:

```text
현재가     52,000
기준가     50,000
----------------
가격 변화   +2,000
등락률        +4%
```

# 11. 차트 가격 범위

차트의 전체 가격 범위를 구한다.

```cpp
range =
    maxPrice - minPrice;
```

예:

```cpp
maxPrice = 73500;
minPrice = 68200;
```

```cpp
range = 5300;
```

이 값은 Y 좌표 변환에서 핵심적으로 사용된다.

# 12. 캔들 몸통 위치 계산

시가와 종가를 Y 좌표로 변환한다.

```cpp
yOpen  = GetYPos(openPrice);
yClose = GetYPos(closePrice);
```

그 다음:

```cpp
bodyTop =
    min(yOpen, yClose);

bodyBottom =
    max(yOpen, yClose);

bodyHeight =
    bodyBottom - bodyTop;
```

개념적으로:

```text
        고가
         │
         │
     ┌───────┐
     │       │
     │ 몸통  │
     │       │
     └───────┘
         │
         │
        저가
```

# 13. 화면 영역을 비율로 분할

가격 차트와 거래량 영역을 나누는 경우 등에 사용한다.

```cpp
chartHeight = rect.Height();

priceHeight  = chartHeight * 0.75;
volumeHeight = chartHeight * 0.25;
```

예:

```text
전체 높이 = 800px

가격 영역 = 600px
거래량 영역 = 200px
```

```text
┌─────────────────────────┐
│                         │
│       가격 차트         │ 75%
│                         │
│                         │
├─────────────────────────┤
│       거래량            │ 25%
└─────────────────────────┘
```

# 14. Clamping

값이 지정된 범위를 벗어나지 않도록 제한한다.

```cpp
value =
    max(minValue,
        min(value, maxValue));
```

C++17 이상이라면:

```cpp
value =
    std::clamp(value, minValue, maxValue);
```

예:

```text
범위 : 0 ~ 100

120 → 100
 80 → 80
-20 → 0
```

차트 좌표가 영역 밖으로 나가는 것을 방지할 때 유용하다.

# 15. 차트 좌표 변환의 전체 구조

차트 프로그램은 결국 다음 구조로 이해할 수 있다.

```text
             데이터 공간
                 │
                 │
                 ▼
        ┌─────────────────┐
        │    Normalization │
        │       0 ~ 1      │
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │  Screen Mapping │
        │    Pixel 좌표    │
        └────────┬────────┘
                 │
                 ▼
           Windows 화면
```

예를 들어 주가가:

```text
75,000원
```

이고 차트의 가격 범위가:

```text
70,000 ~ 80,000
```

이라면:

```text
75,000
   ↓
정규화
   ↓
0.5
   ↓
차트 높이 600px
   ↓
Y 좌표 300px
```

# 16. 가장 중요한 공식들의 관계

다음 공식들은 서로 별개의 공식처럼 보이지만 사실 같은 원리이다.

### 값 → 비율

```cpp
ratio =
    (value - min) /
    (max - min);
```

### 비율 → 값

```cpp
value =
    min +
    ratio * (max - min);
```

### 값 → 화면 Y

```cpp
y =
    top +
    height * (max - value) /
    (max - min);
```

### 화면 Y → 값

```cpp
value =
    max -
    (y - top) *
    (max - min) /
    height;
```

### Index → 화면 X

```cpp
x =
    left +
    index * width /
    (count - 1);
```

### 화면 X → Index

```cpp
index =
    (x - left) *
    (count - 1) /
    width;
```

# 17. 핵심 개념

차트 개발에서는 공식을 개별적으로 암기하기보다 다음 개념을 이해하는 것이 중요하다.

```text
Normalization
     │
     ▼
0 ~ 1 사이의 비율로 변환
     │
     ▼
Linear Interpolation
     │
     ▼
다른 범위로 변환
     │
     ▼
Screen Coordinate
```

즉,

> **데이터 좌표계 ↔ 화면 좌표계**

를 서로 변환하는 것이 차트의 핵심이다.

가격 차트뿐만 아니라 다음에도 같은 원리가 적용된다.

- 주식 차트
- 거래량 차트
- RSI / MACD 등 보조지표
- Slider
- Progress Bar
- Gauge
- 온도계
- 그래프
- 확대/축소(Zoom)
- Crosshair
- 마우스 위치 → 데이터 값 변환
- 데이터 Index → 화면 위치 변환

# 18. HTS 차트 개발에서 특히 기억할 것

질문자님의 MFC 차트 개발 관점에서는 다음 네 가지를 가장 먼저 익히는 것이 좋다.

```cpp
// ① 데이터 → 0~1
ratio = (value - min) / (max - min);

// ② 0~1 → 데이터
value = min + ratio * (max - min);

// ③ 데이터 → 화면
y = top + height * (max - value) / (max - min);

// ④ 화면 → 데이터
value = max - (y - top) * (max - min) / height;
```

특히 **③과 ④는 서로 역변환 관계**이다.

따라서 차트에서

```text
가격 → 화면
```

을 구현했다면,

```text
화면 → 가격
```

도 거의 자동으로 만들 수 있다.

이 관계를 이해하면 `getYPos()`, `getXPos()`, `GetPriceFromY()`, `GetIndexFromX()` 등의 차트 관련 함수들을 읽고 설계하기가 훨씬 쉬워진다.

# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 저장소 성격

이 저장소는 소스코드가 아니라 **개인 문서/노트 모음**이다 (git으로 이력만 관리). 빌드/린트/테스트 명령은 없다. 대부분 마크다운 문서 작성·정리 작업이다.

## 폴더 구조

- `프로젝트 관리/` — 여러 회사/개인 소프트웨어 프로젝트의 진행 현황을 추적하는 폴더. 아래 "프로젝트 관리 워크플로우" 참고.
- `부동산 재테크/`, `주식 재테크/` — 주제별 재테크 노트. claude.ai 대화 내용을 붙여넣어 md로 정리하는 방식으로 누적됨.
- `독서/` — 독서 관련 노트.

## 프로젝트 관리 워크플로우 (`프로젝트 관리/`)

- 신규 프로젝트 시작 시 `템플릿/프로젝트_템플릿.md`를 `프로젝트별/{프로젝트명}/프로젝트.md`로 복사해 작성하고, `README.md`의 프로젝트 목록 표에 행을 추가한다.
- 상태 값은 `착수예정 / 진행중 / 보류 / 완료` 네 가지로 고정.
- 각 `프로젝트.md`는 개요(목적/구분/관련 경로) → 상태 → 다음 할일 → (필요시 세부 분석/이력) → 이력(날짜별 표) 순서로 구성된다. 새 진행사항은 본문에 추가하고 마지막에 이력 표에도 한 줄 남긴다.
- `관련 경로`에는 이 저장소 밖의 실제 소스/자료 위치(예: `D:\src\IBKS\...`)가 자주 나온다 — 해당 프로젝트의 실제 코드나 상세 자료는 이 문서 저장소가 아니라 그 경로에 있다는 뜻이므로, 실제 작업은 그쪽 저장소에서 이루어진다.
- 회사 프로젝트 5개(KRX 애프터장추가, 해외주식 API, HTS 안정화)와 개인 프로젝트 2개(axisBuilder 파이썬, 자동매매 프로그램)가 현재 추적 중이며, 최신 상태는 `README.md` 표와 각 `프로젝트.md`를 확인해야 한다(이 문서에 상태를 중복 기재하지 않음 — 자주 바뀜).

## 인코딩 주의

`독서/claude code 활용 가이드/contents`는 CP949로 저장되어 있고 UTF-8이 아니다 (저장소 내 다른 `.md` 문서들은 UTF-8). 이런 파일을 Edit/Write로 직접 건드리면 한글 바이트열 전체가 깨질 수 있다. 수정이 필요하면:

1. `iconv -f CP949 -t UTF-8 "<path>" > "<path>.utf8.tmp"`로 임시 UTF-8 사본 생성
2. `.utf8.tmp`를 Read/Edit로 수정
3. `iconv -f UTF-8 -t CP949 "<path>.utf8.tmp" > "<path>"`로 원본 위치에 되돌려 쓰기, `.utf8.tmp` 삭제
4. `git diff --stat`으로 변경 줄 수가 의도한 범위인지 검증

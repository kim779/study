# 전북 고창 토지 매도 프로젝트

> 원본: 카카오톡 가족 대화 + 등기부등본 사진 공유 (2026-09-13 정리)

## 1. 배경

- 소유자: **어머니 명의**
- 상속 경위: 1993년 1월 15일 아버지(김완수, 이후 착오정정으로 "김관수"로 등기명의인 표시경정) 사망 → 협의분할에 의한 상속으로 취득
- 같은 1993년 상속재산에 **잠실주공5단지 아파트**([잠실주공5단지_매도전략.md](잠실주공5단지_매도전략.md))도 포함되어 있음 — 이 고창 토지는 별도 갈래의 상속재산
- 어머니 명의 보유 부동산: 전라북도 고창군 고창읍 도산리 **462-1(대지), 462-7(대지), 460(전)** 및 그 외 농지·임야 약간

## 2. 이번 매도 건 (2026-09 진행)

### 2-1. 462-1(대지), 462-7(대지) → A씨에게 매도
- 다음주 수요일 **가계약** 예정
- 상대적으로 단순한 건 (지목상 문제 없음)

### 2-2. 460(전, 91평) → B씨에게 매도 — 복잡한 건
- 현황: 91평 중 **60평은 밭(전)으로 사용**, **31평은 대지처럼 사용 중이며 그 위에 창고 건물**이 있음
- 문제: 지목이 "전"인 상태에서 건물(창고)이 있는 31평을 그대로 매도·이전하면 위법 소지 — 지목변경/분할 없이는 건축물 있는 부분 매매가 어려움
- 해결 방안(가족 논의 내용):
  1. 91평을 **60평/31평으로 분할**
  2. 60평(밭 부분)은 정상적으로 매매계약 체결 및 **소유권 이전**
  3. 31평(창고 부분)은 지목 문제로 즉시 이전이 어려우므로, **B씨로부터 91평 전체 대금을 먼저 수령**하되 31평에 대해서는 **B씨 앞으로 권리 보전 조치(가등기 등)를 설정**해 나중에 이전해주기로 함 — 가족 대화에서 "이재명처럼"이라고 비유(뉴스에서 언급된 매도자 근저당/가등기 방식 연상)

3. A씨와 462-1, 462-7 가계약 — 계약서 작성, 계약금 수수, 등기부등본 재확인 후 서명
4. B씨와 460번지 계약 — 60평 매매계약서 + 31평 가등기(또는 대체 안전장치) 설정 서류, 91평 전체 대금 지급방식 최종 확인 후 서명
5. (필요시) 법무사 사무실 방문 — 등기 접수용 서류 전달

## 4. 주의사항

- **31평 대금까지 먼저 받는 구조**이므로, 나중에 실제로 분할·지목변경이 완료돼 31평도 이전해줄 수 있는지가 핵심 리스크 — 계약서에 이전 기한과 미이행 시 조치를 명확히 넣을 것
- 등기부등본은 **계약 당일 재열람**해서 권리변동 여부 반드시 재확인
- 분할+가등기가 걸린 복잡한 거래이므로 **법무사 개입 여부**를 확인하고, 없다면 당일 현장에서 법무사를 통해 진행하는 것이 안전
- 동생(민식)도 "사기 당하지 말고 잘 보고 오라"고 당부한 부분 — B씨 신원·대금 지급 능력 확인 권장

## 5. 예상 서류 목록 및 서류별 주의사항 (2026-09-13 정리, 09-14 발급방법 보완)

### 5-0. 선행 확인 — 현재 소유자 구성부터 확인할 것

사진 속 등기부에 "대위자 박경자 / 대위원인: 1993.1.15 사망으로 인한 소유권이전등기청구권보전"이라는 문구가 있음 — 이는 상속인으로서 권리를 **보전**한 기록일 뿐, 어머니 단독소유로 확정 정리됐다는 뜻은 아님. 462-1·462-7·460이 **어머니 단독 명의인지, 형제들과 공유(잠실5단지 아파트처럼 지분 분할)인지 먼저 확인 필요**.
- **발급방법**: 대법원 인터넷등기소(iros.go.kr) 또는 무인발급기·등기소 방문으로 **등기사항전부증명서(말소사항 포함)** 발급 → "갑구"의 최종 소유자 확인
- 소유자가 박경자(어머니) 1인 → 5-1 서류만 준비
- 공유자가 여럿 → 전원의 인감증명서·신분증·인감도장(또는 위임장) 각각 필요

### 5-2. 462-1·462-7 매매계약서 (A씨 — 비교적 단순)

- **발급방법**: 통상 공인중개사 또는 법무사가 표준양식으로 작성해 현장에서 서명 — 별도 발급 절차 없음, 사전에 초안을 미리 받아 검토만 해둘 것
- 목적물 표시(지번·지목·면적)가 등기부·토지대장과 정확히 일치하는지 확인
- 계약금/중도금/잔금 일정·금액·입금계좌, 위약금·해제조항 확인
- 공인중개사 개입 시 표준계약서 양식 사용 여부 확인

### 5-4. 460번지 매매계약서 (B씨 — 특약 필요)

- **발급방법**: 5-2와 동일(현장 작성) — 다만 분할·가등기 조건이 들어가는 만큼 법무사가 작성하는 것을 권장
- 특약사항에 반드시 명시: "본 토지는 60평/31평으로 분할 예정이며, 60평은 (지목변경 완료 후) 소유권 이전, 31평은 지목변경·분할 완료 후 별도 이전하며 그때까지 매수인 앞으로 가등기를 설정한다" 등 **이전 시기·조건·기한**
- 91평 전체 대금을 먼저 받는 구조이므로, **미이행 시(분할·지목변경 실패 등) 처리방안(위약금, 원상회복 등)**도 넣을 것

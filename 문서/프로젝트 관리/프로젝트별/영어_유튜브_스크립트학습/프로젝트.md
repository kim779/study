# 영어 유튜브 스크립트 학습

## 개요
- 목적: 출퇴근길에 듣기만 하고 흘려보내는 영어 유튜브 영상에서, 중요한 문장을 스크립트(영어+해석)로 남겨 반복해서 보며 체득한다.
- 관련 경로: `프로젝트별/영어_유튜브_스크립트학습/스크립트/` (영상별 md 파일)

## 진행 방식
1. 유튜브 URL을 전달한다.
2. 자막/스크립트를 확인해 핵심 문장(표현, 자주 쓰이는 패턴 위주)을 추출한다.
3. `스크립트/{날짜}_{영상제목}.md` 파일로 정리한다. 형식:
   ```
   # {영상 제목}
   - URL: {유튜브 URL}
   - 날짜: {YYYY-MM-DD}

   ## 핵심 문장
   - EN: ...
     KR: ...
   ```
4. 이 문서(프로젝트.md)의 이력 표에 진행 내역을 한 줄 남긴다.

## 상태
- 현재 상태: 진행중
- 진행률: 시작 단계

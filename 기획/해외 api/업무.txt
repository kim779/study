1) Open API 제작 (해외주식 화면)
 대상 업무는 해외주식 화면 기준이며, API 제작 및 업무 분석 범위는 아래와 같습니다.

  * 화면 5500: 해외주식 주문 API
  * 화면 5580: 주문 체결 내역 API
  * 화면 5900: 외화 환전 API
      * 대략 5개 전문 연계 및 업무 로직 적용 필요
  * 화면 5620: 잔고거래내역 API
  * 화면 5600: 해외주식잔고 API
  * 화면 5640: 해외주식 거래내역 API
  * 화면 1401: 주식거래내역 API

  또한, 전문에 대한 in/out 업무 정의와 Open API 제공을 위한 API 가이드 문서 작성도 포함하여 산정 부탁드립니다.

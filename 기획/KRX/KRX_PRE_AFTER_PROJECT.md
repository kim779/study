## 개요

KRX 프리마켓 적용호가 도입 및 NXT GTP 주문 추가에 따른 HTS 개발 대응.  
기획서 날짜: 2026-05-11 (작성자: 윤영선)

---

## 작업 항목

### 1. KRX 장전시간외 주문유형 추가 (KRX ③ 그룹)
- 기존 통합 ① 코스피/코스닥/ETF 주문구분에는 없던 유형
- KRX 시장에 **81 장전시간외**, **61 장전시간외** 주문유형 추가
- 대상: 코스피, 코스닥, ETF, ETN, 리츠, 스팩, 상장원수의증권
- [ ] 주문화면 주문구분 콤보박스에 KRX 전용 유형 반영

### 2. NXT GTP (Good Till Premarket) 주문 추가 (NXT ② 그룹)
- GTP = NXT 프리마켓에서 즉시 체결 후 미체결잔량을 프리마켓 종료시까지 호가 대기
- 추가 유형: **NN 지정가(GTP)**, **NN 최유리(GTP)**, **NN 최우선(GTP)**
- 매수/매도 화면 각각 적용
- [ ] 주문구분 콤보에 GTP 유형 추가
- [ ] GTP 안내 팝업 (이미 기획 이미지 확인)

### 3. 시간외단일가 바로가기 버튼 삭제
- [5000](IB105000) 시간외단일가종합화면 메뉴 삭제에 따른 후속 처리
- 변경: `현 체 잔 예 단` → `단(BUTTON0)` 버튼 삭제 → `현 체 잔 예`
- 삭제 후 남은 버튼들 우측 이동 (필요 시)
- [x] 영향 파일 목록 확정 (아래 참고)
- [x] 각 파일 BUTTON0 삭제 및 스크립트 정리
- [x] BTN01~04 우측 이동 (삭제된 버튼 1개 너비만큼) — 전체 9개 파일 완료
